\section{Research Objectives \& Core Contributions}

Modern neural architectures face two fundamental boundaries: \textbf{(1)} autonomous recursive learning often suffers from self-referential error amplification, causing policy collapse unless bounded by external verifiers; and \textbf{(2)} compact sub-billion parameter language models possess virtually zero zero-shot competence in non-Latin, low-resource scripts such as Amharic.

This dual-track investigation establishes:
\begin{itemize}[leftmargin=1.5cm]
    \item[\textbf{Track 1:}] A closed-loop, budget-parity recursive self-learning engine on Connect-4 with an infallible Pascal Pons C++ bitboard solver referee. We prove that \textbf{hard negative mistake-mining} paired with an \textbf{outcome-preserving metric} produces monotonic capability gains ($60.5\% \to 64.0\%$ strict agreement, $72.0\% \to 73.5\%$ outcome preservation, and $41\% \to 55\%$ win rate against heuristic players), while unverified self-play degrades.
    \item[\textbf{Track 2:}] A 4-bit quantized Low-Rank Adaptation (QLoRA) distillation pipeline transferring Amharic instruction-following capabilities from a 4-billion parameter teacher to a 494M parameter student with only $2.16\text{M}$ trainable parameters ($0.4359\%$), achieving viable inference on edge GPUs within a $1.54\text{ GB}$ memory budget.
\end{itemize}

% ─── SECTION 2: TRACK 1 - VERIFIED RECURSIVE SELF-IMPROVEMENT ─────────────────
\section{Track 1: Verified Recursive Self-Improvement on Connect-4}

\subsection{Algorithmic Workflow \& Failure Mode Safeguards}

The self-improvement cycle executes the following bounded loop:
\[
    \mathcal{M}_r \xrightarrow{\text{Self-Play \& Heuristic Games}} \mathcal{D}_\text{raw} \xrightarrow{\text{Solver Verification}} \mathcal{D}_\text{mistakes} \xrightarrow{\text{Replay Buffer}} \mathcal{M}_{r+1} \xrightarrow{\text{Acceptance Gate}} \text{Deploy or Rollback}
\]

\begin{enumerate}[leftmargin=1.2cm]
    \item \textbf{Infallible Bitboard Solver Referee:} Positions encountered during exploration are resolved via Pascal Pons' C++ bitboard solver backed by an SQLite opening book cache, returning exact game-theoretic win/draw/loss scores ($s \in [-22, +22]$) in sub-millisecond time.
    \item \textbf{Experience Replay Buffer:} Preserves foundational board states from the initial baseline while assimilating newly corrected blunder positions, mathematically bounding catastrophic forgetting.
    \item \textbf{Bilateral Reflection-Symmetric Hashing (Zero-Leakage):} Because Connect-4 is invariant under horizontal reflection, positions are hashed via:
    \[
        h_\text{canonical}(B) = \min\bigl(\mathrm{hash}(B),\; \mathrm{hash}(\mathrm{flip\_lr}(B))\bigr)
    \]
    Partitioning datasets strictly by $h_\text{canonical}$ mathematically guarantees zero leakage across train, dev, and test splits.
    \item \textbf{Active Mistake-Mining (Hard Negative Mining):} In each self-play collection round, $2\times$ candidate positions are sampled and evaluated. Up to $70\%$ of the training batch is prioritized with positions where the model made a suboptimal move ($a_\text{chosen} \notin \mathcal{A}^*$), forcing gradient updates onto policy blind spots.
    \item \textbf{Horizontal Mirror Augmentation:} Every training example is duplicated with its horizontal reflection:
    \[
        (x, y) \implies \bigl(\mathrm{fliplr}(x),\; 6 - y\bigr)
    \]
    yielding a $2\times$ training dataset expansion ($3{,}000$ effective examples/round) at zero additional solver evaluation overhead.
\end{enumerate}

\subsection{Dual Evaluation Protocol \& Elimination of Deterministic Loops}

Previous evaluation iterations suffered from deterministic repetition (alternating sides resulted in the exact same two games repeated 50 times, yielding $0\%$, $50\%$, or $100\%$ artifacts). We resolved this through:
\begin{itemize}[leftmargin=1.2cm]
    \item \textbf{Randomized Openings:} Every match starts with $k \sim \mathcal{U}\{2, 4\}$ uniform random opening plies before handing control to the competing policies, evaluated over $100$ games per opponent.
    \item \textbf{Strict Optimal vs. Outcome-Preserving Metric:}
    \begin{align*}
        \text{Strict Optimal:} \quad & \hat{a} \in \mathcal{A}^* \iff s(\hat{a}) = \max_{a} s(a) \\
        \text{Outcome-Preserving:} \quad & \begin{cases}
            s(\hat{a}) > 0 & \text{if } \max_a s(a) > 0 \quad (\text{Forced win preserved}) \\
            s(\hat{a}) = 0 & \text{if } \max_a s(a) = 0 \quad (\text{Forced draw preserved}) \\
            s(\hat{a}) = \max_a s(a) & \text{if } \max_a s(a) < 0 \quad (\text{Optimal defense/slowest loss})
        \end{cases}
    \end{align*}
\end{itemize}

\subsection{Qualitative Analysis \& Linguistic Findings}

\begin{itemize}[leftmargin=1.2cm]
    \item \textbf{Base Model Failure Modes:} The base student suffered from catastrophic script mixing (interspersing random Chinese, Latin, and Cyrillic characters), infinite character loops, and direct prompt copying without generating an answer.
    \item \textbf{Distilled Model Improvements:} The distilled adapter demonstrated rapid internalization of proper Ethiopic orthography, courteous Amharic conversational openers (e.g., \textit{``ጤና ይስጥልኝ...''}), and structural task alignment across translation and summarization prompts.
    \item \textbf{Remaining Limitations:} While syntax, grammar, and script integrity improved markedly, semantic hallucination and repetitive terminal phrases persisted on complex multi-hop queries, confirming that 1,843 examples suffice for surface form adaptation but full factual alignment requires scaled pre-training.
\end{itemize}
